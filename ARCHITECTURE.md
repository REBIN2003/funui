> Generated by codebase-mapper on 2026-10-24

## Overview

The workspace contains two distinct UI component ecosystem codebases in a single repository:
1. **Root (`shadcn-studio`)**: A full-stack Next.js 16 (App Router) web application and registry server built by ThemeSelection for previewing, customizing, generating themes for, and distributing copy-and-paste shadcn/ui components and pre-built blocks. Deployed to Netlify (`https://funui1.netlify.app`).
2. **Subfolder (`react/`)**: The open-source `@untitledui/react` component library (formerly Untitled UI React), built with React 19, Tailwind CSS v4, React Aria Components, and Storybook / Vite.

## Components & Structure

### 1. Root Application (`shadcn-studio`)
- **Purpose:** Presentation web application, interactive theme generator, catalog browser, and registry distribution server for shadcn/ui components.
- **Entry Points:**
  - `src/app/layout.tsx`: Root HTML layout, font setup, theme providers, global metadata.
  - `src/app/(front)/theme-generator/page.tsx`: Default landing destination (redirected from `/`).
  - `src/app/(front)/components/page.tsx`: Component catalog index.
  - `src/app/(front)/blocks/page.tsx`: Page blocks showcase.
  - `src/app/(pages)/docs/components/[category]/page.tsx`: Dynamic component detail & code viewer.
  - `src/app/(blank)/preview/...`: Isolated iframe/standalone preview rendering for blocks and components.
- **Key Modules:**
  - `src/config/components.tsx`: Definition of all component categories, navigation items, and icons.
  - `src/config/theme.ts`: Presets and configurations for the Theme Generator.
  - `src/components/layout/`: App shell, Header, Footer, Sidebar, ModeToggle, CommandMenu, and Logo (`logo.tsx`).
  - `src/components/shadcn-studio/`: Source code of all customizable component variants and blocks.
  - `src/components/ui/`: Core shadcn/ui primitives (Radix UI wrappers).
  - `src/utils/components.ts` & `src/utils/serverHelpers.ts`: Server-side file reading and CSS variable extraction.
  - `registry.json` & `public/r/*.json`: Distribution manifests for `npx shadcn add` CLI integration.

### 2. Embedded Library (`react/` - Untitled UI)
- **Purpose:** Standalone, accessible component system built on React Aria Components and Tailwind CSS v4.
- **Entry Points:**
  - `.storybook/main.ts` & `vite.config.mts`: Storybook development and build environment.
  - `react/components/index.ts` (or module exports) for base, application, foundations, and shared assets.
- **Key Modules:**
  - `react/components/base/`: Fundamental interactive controls (buttons, inputs, dropdowns, avatars, tags, badges).
  - `react/components/application/`: Complex patterns (app navigation, dual-tier sidebar, modals, data tables, date pickers).
  - `react/components/foundations/logo/`: Untitled UI logo implementations (`untitledui-logo.tsx`, `untitledui-logo-minimal.tsx`).
  - `react/styles/`: Tailwind v4 theme, tokens, and typography sheets (`globals.css`, `theme.css`, `typography.css`).

## Data Flow

1. **User Page Request:** User accesses `https://funui1.netlify.app` -> Root layout reads cookie `shadcn-studio-mode` for theme preferences.
2. **Component Catalog View:** `components/page.tsx` parses categories from `src/config/components.tsx`.
3. **Live Preview / Code Inspection:** Server reads local files directly via `src/utils/serverHelpers.ts` (`getFileContent()`) from `src/components/shadcn-studio/...` without external HTTP round-trips.
4. **Registry CLI Installation:** Developers run `npx shadcn@latest add https://funui1.netlify.app/r/{component}.json`, which downloads self-contained JSON manifests from `public/r/` generated by `npm run registry:build`.

## Conventions
- **Root (`shadcn-studio`):** Next.js App Router, `@/*` pointing to `./src/*`, Lucide icons, kebab-case component IDs (`accordion-01`), Tailwind v4 CSS variables.
- **Sub-library (`react/`):** React Aria Components prefixed with `Aria*`, `@/*` pointing to `react/*`, `@untitledui/icons` for symbols, strict kebab-case file naming, compound component patterns.

## Technical Debt & Boundary Risks
- [ ] Root `tsconfig.json` does not exclude `react/`, causing `tsc --noEmit` and potential Netlify builds to fail due to conflicting path aliases and missing packages.
- [ ] Direct references to ThemeSelection, shadcn/studio CDN (`cdn.shadcnstudio.com`), social channels, and documentation URLs hardcoded in layout files.
- [ ] `react/` dependencies (`@untitledui/icons`, etc.) are not installed in the workspace root.
- [ ] Dual logo and naming touchpoints require coordinated replacement to ensure unified branding.
